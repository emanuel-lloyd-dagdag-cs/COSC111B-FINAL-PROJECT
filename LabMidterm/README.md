Midterm Laboratory Practical Exam

This code implements a smart outdoor lighting monitor that reads ambient light levels via a photoresistor and activates a Green, Yellow, or Red LED to indicate intensity. It features dual operating modes: an "Automatic" mode that uses fixed rules to simulate environmental conditions, and a "Manual" mode that allows users to configure their own custom sensitivity thresholds. Users control the device entirely through the Serial Monitor, typing text commands like MODE AUTO or SET HIGH 80 to change settings while viewing real-time status updates.
