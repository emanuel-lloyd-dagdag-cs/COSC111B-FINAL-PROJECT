Laboratory Activity #5

This project creates a remote-controlled lighting system where a Python script on your computer communicates with an Arduino via USB. The user sends single-letter commands (like 'R', 'G', or 'A') to the Arduino, which interprets them to toggle Red, Green, and Blue LEDs or turn them all on at once. After changing the lights, the Arduino sends a text confirmation back to the computer, which the Python program displays to verify the action was successful.
