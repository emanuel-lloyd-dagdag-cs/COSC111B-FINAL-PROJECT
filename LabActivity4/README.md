Laboratory Activity #4

This activity creates another temperature alarm but this time it is a manual alarm. It checks the temperature once every second and prints the result to your computer screen. If the sensor detects heat above 50°C, it triggers a permanent "Alert Mode" where the LED starts flashing. Unlike a normal sensor, this alarm will not turn off even if the temperature drops back down; it stays active until you manually type the word "stop" into the Serial Monitor to reset it.
