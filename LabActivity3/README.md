Laboratory Activity #3

This activity creates a Fire Alarm System that uses two different sensors to detect danger.

It constantly monitors the room's temperature (using a thermistor) and light level (using a photoresistor). If the system detects both high heat (above 50°C) and bright light (indicating a flame), it triggers a rapid alarm, flashing the LED and beeping the buzzer on and off very quickly. It also sends the temperature and brightness numbers to your computer screen so you can see the live readings.
